# A Cancellation refunds without the Admin unless the Artisan disputes

Before Work started, either party may cancel and the Client is refunded at once. After Work started, the Materials stay with the Artisan and the unreleased Labour is refunded after 72 hours, unless the Artisan opens a Dispute for work already done. Having the Admin allocate every Cancellation, as the brief proposed, was rejected because one Admin would then decide routine endings that both parties accept.
