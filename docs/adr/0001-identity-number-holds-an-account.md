# An Account is held by one Identity Number per kind

An Account is not held until the named person's Identity Number is recorded. That number is unique for a Client Account and unique for an Artisan Account. Closing does not free a number that was the named person's. A second Account of the same kind would split Reviews, the Reliability Record, and the Client Relationship, and would let the same human hire themselves. A closed Account's number may be freed only when it is found not to be theirs, so the person it belongs to can hold an Account. The closed Account keeps that history. A correction is not a release. Email alone was rejected because an email is not a person. An asylum-seeker permit was rejected because the key would expire.
