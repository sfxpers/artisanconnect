# An Account is held by one Identity Number per kind

An Account is not held until the named person's Identity Number is recorded. That number is unique for a Client Account and unique for an Artisan Account, and closing the Account does not free it. A second Account of the same kind would split Reviews, the Reliability Record, and the Client Relationship, and would let the same human hire themselves. Email alone was rejected because an email is not a person. An asylum-seeker permit was rejected because the key would expire.
