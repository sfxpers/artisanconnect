# One Review scorecard for every Service Category

The brief let each Service Category define its own Review dimensions, and an Admin manage those rules. She scores him on the same four in every category: workmanship, agreed work, punctuality, and communication. The category already scopes whose Reviews count, so a second list would make that average a different instrument. A Visitor never sees the comment, only the average, which is why the state of the site sits inside workmanship rather than in a fifth question or in the comment alone. His four are unchanged.
