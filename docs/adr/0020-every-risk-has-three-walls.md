# Every risk has three walls: detection, an Admin pre-check, and Reports

Everything that can go wrong is stopped by three walls in order. First, detection: the Content check and the behaviour Signals. A sure hit is refused, an unsure one is Held for the Admin, and a Signal becomes a queue item, never an automatic sanction. Second, the Admin checks beforehand what is reasonable to check: Verification, every Artisan Profile edit, every Review, an unsure certificate, and every Held item. A Held item does not exist for anyone else until it is released, and there is no time limit, so nothing doubtful passes by timeout. Third, Reports from Accounts, for what both walls missed. A check that only passed or refused was rejected because a doubtful item then had to be guessed one way or the other with no person looking. Pre-checking every Job, message, or Client was rejected as more than a small Admin team can hold. Automatic sanctions from Signals were rejected because shared phones and Wi-Fi are common in South Africa.
