# Money moves by Milestone, all funded at Hire

The flow follows Upwork's fixed-price milestones. A Quote splits its price into one or more Milestones, and the Client pays for all of them at Hire. The Artisan submits each Milestone with a note and a photo; the Client Releases it, requests changes, or opens a Dispute, and a Submission left unanswered for 72 hours is Released. Added work is a new Milestone the Client accepts by paying for it, and a lower price is the Artisan's Return. A materials deposit is a first Milestone, and a paid site visit is a one-Milestone Quote. Releasing nothing until all the work was done was rejected because South African Artisans would have to buy all materials up front. Funding one Milestone at a time was rejected because the Artisan would then start later stages without knowing the money exists. Upwork's 14-day review was shortened to 72 hours because work on a site is inspected on the day and Artisans need the cash.
