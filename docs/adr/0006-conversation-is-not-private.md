# A Conversation is not private from the platform

A Conversation may be read, and an Admin may not speak in it. The Admin opens one only from a Report, a Dispute, or a Chargeback on that Job, every read is logged, and there is no search of every Conversation. Both parties are told that it may be read before the first message. End-to-end privacy was rejected because Leaving and a Dispute would then be unjudgeable. The notice wording is not this decision. A support queue was rejected because a report already opens the record.
