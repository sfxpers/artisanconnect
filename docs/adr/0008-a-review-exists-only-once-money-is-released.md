# A Review exists only once an Engagement is Completed

A Review is written only once every Milestone is Released or Returned and some money was Released. An Engagement Returned in full has none. Neither party can read the other's until both submit or 14 days pass, and a side that misses the window cannot write later. There is no Dispute mark. Reviewing any paid Engagement was rejected because a Review must cost a real, released payment, which makes faked Reviews expensive.
