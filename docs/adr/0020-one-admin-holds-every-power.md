# One Admin holds every power

Launch has one Admin, created by a setup command, holding every staff power and logged on every act. Separate grants, a rule that a different person hears each challenge, and staff invitations were rejected because one person runs launch, and such rules would leave a challenge waiting for a second Admin who does not exist. A suspended Account sees the reason and writes to support@, and the Admin may lift any Suspension. More Admins, with the same powers, can be added later.
