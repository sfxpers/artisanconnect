# Hire Again is an Invite-only Job

Hire Again opens a new Invite-only Job, prefilled from a Completed Engagement and inviting only that Artisan. It uses the ordinary Job, Quote, and Hire flow and needs no rule of its own. The Artisan Fee for that Client Relationship is already the repeat rate. A direct offer that skipped the Quote was rejected because it would be a second way to agree a price.
