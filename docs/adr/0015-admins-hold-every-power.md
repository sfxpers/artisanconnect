# Every Admin holds every power

The first Admin is created by a setup command. An Admin may invite another Admin by Email and may remove one, but never the last. Every Admin holds every staff power, and every act is logged. Separate grants and a rule that a different person hears each challenge were rejected: they need a staffing model launch does not have, and they would leave a challenge waiting for a second Admin. A suspended Account sees the reason, may send a Support request, and the Admin may lift any Suspension.
