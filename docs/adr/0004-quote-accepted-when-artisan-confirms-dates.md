# A Quote is accepted when the Artisan confirms the dates

A Client does not accept a Quote alone. The Client enters a start date and a duration, and the Quote is accepted only when the Artisan confirms them. That confirmation locks the price and scope, and every other Sent Quote becomes Not chosen. Those Quotes do not return if the Client never pays. The Client's click alone was rejected because the Artisan's withdrawal would then strand the Client: the others would already be dead, and the Artisan cannot withdraw once the Quote is accepted. Letting the Client switch before Payment was rejected because accepting already stops new arrivals, and bringing the others back would reopen who can see the Job.
